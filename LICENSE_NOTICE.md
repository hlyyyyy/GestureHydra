# License Notice

This repository scaffold intentionally does not ship with a final code license yet.

Before making the project fully public, please decide and add licenses for:

- code
- dataset annotations and metadata
- model checkpoints
- demo assets and videos

Recommended release workflow:

1. Choose a software license for the source code.
2. Add a separate notice for data usage terms if the dataset has restrictions.
3. Clarify whether model weights are released under the same terms as code.
4. Update `README.md` and `CITATION.cff` with the final repository URL and license.

Until then, treat this repository as a private or draft public release.
